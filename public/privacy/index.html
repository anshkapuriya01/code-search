Privacy

Last updated 10 November 2026. This notice explains what Code Search (codesearch.amplfyd.com, part of amplfyd) stores when you use it, and why.

What we store

  • Your GitHub user id, login, display name and avatar URL, so the dashboard can show who is signed in.
  • The GitHub access token GitHub gives us when you sign in, encrypted with AES-256-GCM. It has no scopes, so it can only read public data. We use it only to run your searches and README reads on your own GitHub quota.
  • SHA-256 hashes of your session cookie and your API keys, plus each key's name, first characters, creation date and when it was last used.
  • Hourly counts of your API calls per key and endpoint (how many, and whether they succeeded, were rate-limited or came from cache), kept for 90 days for the Usage tab.
  • Your total number of requests, searches and AI use per day (no search text), kept for 31 days to enforce the daily limits.
  • A log of each call made with your account: when it happened, which key or the dashboard made it, what you searched for or which README you asked for, the results returned (repository names, stars, language, licence and a short description, or the first 1,000 characters of a README), whether it worked, your browser or agent's User-Agent and your country. We also record sign-ins and API key changes. The log is kept for up to 90 days and is visible to the people who run Code Search, so they can operate the service and stop abuse. It never contains your API keys, tokens or IP address.

What we do not store

  • Your password. Sign-in happens on GitHub's own page.
  • Your private repositories. The token cannot see them.

Who else is involved

  • GitHub, which handles sign-in and answers every search.
  • Cloudflare, which hosts the site, the database and the cache, and whose Workers AI service reads the text of your search to work out what to look for. Your account is not sent with it.

Cookies

One sign-in cookie (HttpOnly, SameSite=Lax) and a short-lived cookie that protects the sign-in step. No advertising or analytics cookies.

Deleting your data

Delete your account from the dashboard under Account. Your keys, sessions, token, usage counts and call log are removed and Code Search's access to your GitHub account is revoked in the same step. Only today's request counter stays, with no search text, until the next daily clean-up, so deleting an account cannot reset a daily limit.
