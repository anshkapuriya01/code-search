[ 03 / 07 ] · How it worksfour steps

      

        

          Behind the scenes
          
From a sentence to the right project

        

        

          

            
Step 1

            
Skip the filler. Words about you, like “I need” or “for my team”, are left out.

            
I need an open source alternative to notion that I can self host

          

          

            
Step 2

            
Find the key words. Some must match. Others just help the best ones rise.

            
Must have notion
Nice to have alternative self-hosted

          

          

            
Step 3

            
Throw out spam. Repos stuffed with keywords are removed.

    [ 07 / 07 ] · FAQ9 questions
    
      
    
        
    
          
    Questions
    
          
    Short answers. More in the docs.
    
          Read the docs →
        
    
        
    

    Q.01Is Code Search free?
    Yes. Every plan costs $0. Searches run on your own GitHub account, so there is no bill to pass on.
    

    Q.02Do I need to install anything?
    No. Sign in with GitHub and search in your browser. You only touch a config file if you want an AI agent to use it.
    

    Q.03How many searches can I run?
    GitHub gives each account 30 searches a minute. That limit is yours alone, and repeat searches come from a cache for free.
    

    Q.04Can it see my private code?
    No. Code Search asks GitHub for no extra permissions, so it can only read public projects.
    

    Q.05What do you store about me?
    Your GitHub name and picture, and your GitHub token, encrypted. Keys and sessions are stored only as hashes.
    

    Q.06Which AI agents work with it?
    Claude Code, Codex, Cursor, Grok, GitHub Copilot, Windsurf, Gemini CLI, Cline, Amp and any other MCP client. Anything else can use the REST API.
    

    Q.07How is it different from GitHub search?
    GitHub needs exact keywords. Code Search takes a normal sentence, removes spam and tiny projects, and shows the best matches first.
    

    Q.08What is trending first?
    For popular topics we keep a hand-picked list of trending projects. When your search matches a topic, those projects show at the top, marked Trending.
    

    Q.09How do I delete my account?
    Open the dashboard, go to Account and press Delete. Your keys, sessions and token are removed right away.
