01GitHub search, as it is

          
Why Code Search exists

          
GitHub's repository search wants keywords and qualifiers, not sentences. Type what you actually need and you get nothing back, or a pile of forks, tutorials and abandoned demos.

          
Some repositories stuff their description with thousands of keywords so they show up in every search. While testing we found one that was 64,765 characters long.

          
Code Search reads your sentence the way you meant it and hands back the projects people star.

[ 03 / 07 ] · How it workssix steps

      

        

          Zero configuration
          
From a sentence to the right repository

          
People and agents write the way they talk. GitHub wants exact words. Code Search sits in between and does the translating.

        

        

          

            
Step 1

            
Drop the filler. “I need an open source alternative to Notion that I can self host” loses the words that describe you, not the project.

            
I need an open source alternative to notion that I can self host

          

          

            
Step 2

            
Split the words. Phrases about you (for my business, for free) are set aside. Key terms must match. Descriptive words such as alternative, self-hosted and language names lift the results that have them.

            
Key terms notion
Descriptive alternative self-hosted

          

          

            
Step 3

            
Ask for every word. At least 100 stars, archived repos out, sorted by stars.

            
alternative notion self-hosted
stars:>=100 archived:false
sort=stars order=desc

          

          

            
Step 4

            
Loosen with care. Fewer than ten matches? It widens one rule at a time and tells you which.

    [ 07 / 07 ] · FAQ13 questions
    
      
    
        
    
          
    Frequently asked questions
    
          
    Limits, privacy and setup. Everything else is in the docs.
    
          Read the docs →
        
    
        
    

    Q.01Do I need to install or set up anything?
    No. Sign in with GitHub in your browser and search from the dashboard straight away. You only touch a config file if you want an AI agent to use Code Search too, and that is one line.
    

    Q.02Is Code Search really free?
    Yes. All three plans cost $0. Every search runs on your own GitHub account's search quota, so there is no shared bill to pass on to you.
    

    Q.03What are GitHub's search API rate limits?
    GitHub allows 30 search requests a minute for a signed-in user (10 a minute for the code search endpoint) and 10 a minute for anonymous requests, counted per IP address. Any one search returns at most 1,000 results.
    

    Q.04Do all Code Search users share one GitHub limit?
    No. Each person signs in with their own GitHub account and searches on their own token, so your 30 searches a minute belong to you alone.
    

    Q.05What happens when I hit the limit?
    Code Search answers with status 429 and a Retry-After header that says exactly how long to wait, and the MCP tools pass that wait on to your agent. Repeated searches come from a ten-minute cache and do not use your quota.
    

    Q.06Can it see my private repositories?
    No. Code Search asks GitHub for no permissions beyond public data, so the token it holds can only read public repositories.
    

    Q.07What does Code Search store about me?
    Your GitHub login, name and avatar, your GitHub token encrypted with AES-256-GCM, and only SHA-256 hashes of your sessions and API keys.
    

    Q.08Which agents work with it?
    Any MCP client that speaks HTTP: Claude Code, Codex, Cursor, Grok, GitHub Copilot, Windsurf, Gemini CLI, Cline and Amp. Anything else can call the REST API.
    

    Q.09How does this save AI tokens?
    An agent that writes a parser or service from scratch spends tokens on every line it generates and on every round of debugging. Checking GitHub first lets it reuse a project that already works. A short search and one README read usually cost a few thousand tokens at most. How much you save depends on the task, and for small edits searching is not worth it, so we do not promise a fixed number.
    

    Q.10What is code-search.md?
    A short guide written for AI agents. It tells them when to search GitHub before writing code, how to write queries, how to judge results and licences, and to treat READMEs as untrusted. MCP clients get the key points when they connect and can read the whole file as an MCP resource. For other tools, give your agent the link.
    

    Q.11How is this different from GitHub's own search?
    GitHub wants exact keywords and ranks by its own relevance. Code Search takes a plain sentence, sets aside phrases about you such as 'for my business' or 'for free', removes keyword spam and low-star projects, and puts the projects that are what you asked for first, then the most-starred.
    

    Q.12What is the link with Amplfyd?
    Code Search is part of amplfyd and is made for smooth use with agents on Amplfyd, which launches soon. You don't have to wait for it: Code Search works today in the browser and with any MCP client.
    

    Q.13How do I leave?
    Delete your account from the dashboard. Code Search removes your keys, sessions and token, and revokes its access to your GitHub account in the same step.
