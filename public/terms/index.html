The service

Code Search is free. It searches public GitHub repositories on your behalf, using your own GitHub account's quota, and returns the results through the dashboard, the REST API and the MCP server.

  • Keep to the published limits: GitHub's search limit of 30 requests a minute and Code Search's 120 requests a minute per account.
  • Do not try to get around rate limits, for example by creating many GitHub accounts.
